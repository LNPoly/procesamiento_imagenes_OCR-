Procesador de Imágenes y Analizador de Texto

Integrantes del Equipo

  • Juan Manuel Etchehun
  • Alejandro Rodríguez

Con el fin de poder resolver la problemática de que los documentos en forma de imagen (JPG, BMP, PNG, entre otros) decidimos poner en marcha el proyecto mediante el análisis, modificación opcional y manipulación de imagen para después pasar a por un sistema en que se pueda identificar el texto de una imagen y asi poder reconvertirlo en un formato digital editable.

Para la realización de este MVP, utilizamos Python para la codificación junto con las librerias Pillow y OpenCv que son utilizadas para la manipuación de las imágenes. En cuanto al análisis y detección de texto, se utilizó Tesseract y se conectó mediante Flask a una interfaz simple y con un diseño innovador para así, poder darle una apariencia futurista / ciberpunk.
